## ٠· جوهرُ الفكرة في ثلاثة أسطر

١. **الحجبُ غالباً في المصافحة لا في الرؤوس.** بصمةُ TLS تفضح المكتبةَ
   البرمجية، فتُنتحَل بصمةُ متصفّحٍ حقيقيّ فتُفتَح الأبوابُ المغلقة.
٢. **العناوينُ تُكتشَف من الصفحة، لا تُحفَظ في الشيفرة.** البوّاباتُ
   تُولّد معرِّفاتٍ متغيّرةً في المسار؛ والمسارُ المحفوظُ يصمت يومَ يدور.
٣. **الطبقاتُ مرتَّبةٌ بميزتها، والغيابُ يُقال.** رسميٌّ ← ثانويٌّ ←
   مزوِّد، وما لم يُقرأ **يغيب** ولا يُملأ بالتقريب.

## ١· الطبقةُ الأولى: انتحالُ بصمة TLS

### القياسُ الذي غيّر الحكم

كان مكتوباً في ثلاثة ملفّاتٍ من مشروعنا أن «تداول» تردّ **403** على
بيانات السوق، وبُني على ذلك بديلٌ كامل. والقياسُ ردّ السبب:

| المحاولة | النتيجة |
|---|---|
| رؤوسٌ كاملةٌ + جلسةٌ مسخَّنة + `httpx` | **403** |
| نفسُ الرؤوس + `curl_cffi` بانتحال كروم | **200** |

فالحجبُ لم يكن بالرؤوس ولا بالكوكيز: حمايةُ Akamai تُميّز **مُصافحةَ
TLS** لمكتبةٍ برمجيةٍ من مصافحة كروم (ترتيبُ الشيفرات · الامتدادات ·
ALPN · بصمةُ JA3/JA4). ولا تُقلَّد بالرؤوس مهما بلغت.

### الشيفرةُ الكاملة (مَعبرٌ واحدٌ لكلّ المشروع)

```python
"""جلبٌ يعبر حمايةَ البوّابة بنفسه — مَعبرٌ واحدٌ لا جلساتٌ متفرّقة."""
from __future__ import annotations
import asyncio
from loguru import logger

ORIGIN = "https://www.saudiexchange.sa"
HOME = ORIGIN + "/wps/portal/saudiexchange/home"
_IMPERSONATE = "chrome"        # أو "chrome124" لتثبيت إصدارٍ بعينه


def _have_curl() -> bool:
    try:
        import curl_cffi  # noqa: F401
        return True
    except Exception:
        return False


def _blocking_fetch(url, params, referer, timeout):
    from curl_cffi import requests as cr
    with cr.Session(impersonate=_IMPERSONATE) as s:
        # تسخينٌ يجمع كوكيزَ الحماية قبل طلب البيانات — يُحاوَل ويُتجاوَز.
        try:
            s.get(HOME, timeout=timeout)
        except Exception:
            pass
        headers = {"Referer": referer} if referer else None
        r = s.get(url, params=params, headers=headers, timeout=timeout)
        return r.status_code, r.text or ""


async def fetch(url, *, params=None, referer=None, timeout=45):
    """(الحالة، النصّ). الجلبُ المنتحِل متزامنٌ بطبعه — فيُشغَّل في خيط."""
    if _have_curl():
        try:
            return await asyncio.to_thread(
                _blocking_fetch, url, params, referer, timeout)
        except Exception as e:
            logger.warning("انتحالُ الجلب تعذّر ({}) — يُجرَّب البديل", e)
    import httpx                      # بديلٌ لا ينهار بغياب المكتبة
    async with httpx.AsyncClient(timeout=timeout, follow_redirects=True) as c:
        try:
            await c.get(HOME)
        except Exception:
            pass
        r = await c.get(url, params=params,
                        headers={"Referer": referer} if referer else None)
        return r.status_code, r.text or ""
```

**الاعتماد:** `curl_cffi` (تُبنى على `libcurl-impersonate`). وغيابُها لا
يُسقط شيئاً — يعود الحجبُ وحدَه، ويُقال في السجلّ.

### أربعةُ شروطٍ لا تُهمَل

١. **خيطٌ منفصل** (`asyncio.to_thread`): المكتبةُ متزامنة، ووضعُها في حلقة
   الحدث يجمّد الخادم.
٢. **تسخينُ الجلسة**: `GET` للصفحة الرئيسة أوّلاً يجمع كوكيزَ الحماية.
   ويُحاط بـ`try` — فشلُه لا يمنع المحاولة.
٣. **`Referer` صحيح** لنقاط البيانات: الصفحةُ التي تستدعيها عادةً.
٤. **مَعبرٌ واحدٌ** في المشروع كلِّه: تعدُّدُ الجلسات يضاعف الاحتمالَ
   والرؤوسَ ويُخفي سببَ العطب.

## ٢· الطبقةُ الثانية: اكتشافُ نقطة البيانات من الصفحة

### لماذا لا يُحفَظ المسار

بوّاباتُ IBM WebSphere Portal (وهي بنيةُ «تداول») تُولّد مسارات من هذا
الشكل:

```
/wps/portal/saudiexchange/.../!ut/p/z1/<معرِّفٌ طويلٌ متغيّر>/p0/IZ7_...=NJgetMainNomucMarketDetails=/
```

المعرِّفُ يدور بلا إنذار، ومسارٌ محفوظٌ في الشيفرة يصمت يومَ يدور — صمتاً
**لا يُميَّز عن «لا بيانات»**. والثابتُ الوحيدُ هو **اسمُ الخدمة** بعد
`=NJ`.

### القاعدة

```python
import re
_BASE_RE = re.compile(r"<base[^>]+href=[\"']([^\"']+)", re.I)
_EP_RE   = re.compile(r"p0/[A-Za-z0-9_=]*=NJ([A-Za-z]{4,60})=/")

status, body = await fetch(PAGE)            # صفحةُ الشاشة نفسِها
base = _BASE_RE.search(body).group(1).rstrip("/")   # أساسُ الصفحة
names = sorted(set(_EP_RE.findall(body)))           # كلُّ أسماء النداءات

# يُختار النداءُ **بمعناه** لا بترتيبه:
hit = next(n for n in names if re.search(r"foreg|foreign.*owner", n, re.I))
ep  = next(m.group(0) for m in _EP_RE.finditer(body) if m.group(1) == hit)

status, raw = await fetch(f"{base}/{ep}",
                          params={"requestLocale": "en"}, referer=base)
rows = (json.loads(raw) or {}).get("data")
```

### أسماءُ خدماتٍ مقيسةٌ فعلاً (مراجعُ للنقل)

| الاسم | ما يُعيد |
|---|---|
| `getMainNomucMarketDetails` | مراقبةُ السوق الرئيسة — كلُّ الشركات بصفٍّ لكلٍّ |
| `getSukukMarketDetails` | سوقُ الصكوك (منه المعدَّلُ الخالي من المخاطر) |
| `statementsTabData` | تبويبُ القوائم (متجمّدٌ عند 2023 — لا يُعتمَد) |
| `foreginOwnerShip` | الملكيةُ الأجنبية (بالإملاء هكذا في المصدر) |
| `historicalBoardMembersWithDates` | أعضاءُ مجلس الإدارة |
| `ThemeTASIUtilityServlet` | مؤشّرُ تاسي مباشرةً (خدمةُ ترويسةٍ لا بوّابة) |

> **قيدٌ مقيس:** بعضُ المسارات محجوبةٌ **عند الحافّة** لا بالمصافحة —
> `.../participants-and-deals/special-deals` تعود 200 بقشرةٍ بلا جدول
> للجلب المنتحِل، و**403 Access Denied** لمتصفّحٍ حقيقيّ. فليست مسألةَ
> سكربتٍ يُنفَّذ: المسارُ نفسُه ممنوع، ويُطلب من طبقةٍ أخرى.

## ٣· الطبقةُ الثالثة: المتصفّحُ آخرَ الوسائل

انتحالُ البصمة يعبر الحمايةَ ولا **ينفّذ سكربتاً**. وقد قِيس أن صفحاتٍ
عدّةً تعود «200 وصفرَ صفوف» لأن جدولَها يُرسَم بجافاسكربت. فالمتصفّحُ هو
الوسيلةُ الباقية، **مقيَّداً**:

```python
NAV_TIMEOUT_MS, SETTLE_MS, MAX_PAGES_PER_RUN = 25_000, 2_500, 40

def _launch_kwargs() -> dict:
    """كروميومُ الصورة نفسُه — لا نسخةٌ ثانيةٌ تُنزَّل (‏~400MB)."""
    kw = {"args": ["--no-sandbox", "--disable-dev-shm-usage"]}
    p = shutil.which("chromium") or os.environ.get("CHROME_BIN")
    if p:
        kw["executable_path"] = p
    return kw
```

وفي الصورة: `apt install chromium` + `ENV PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`.

**قيودٌ إلزامية:** لا يُشغَّل في مسار طلبِ مستخدم · صفحةٌ واحدةٌ في كلّ
مرّة · مهلةٌ قصوى · إغلاقٌ حتميٌّ في `finally` (عمليةُ كروميوم الباقيةُ
تلتهم الذاكرةَ بصمت) · وغيابُه **حالةٌ معلَنة** (`BrowserUnavailable`) لا
يُخلَط بغياب البيانات.

## ٤· قراءةُ الروابط من صفحةٍ بشرية

حين لا تكون البياناتُ في نقطةٍ بل في صفحةِ موقعٍ عاديّ:

```python
TABS = {                      # المسارُ يحكم، والنصُّ يسند
  "major_holders": (re.compile(r"/major-shareholders/company/"),
                    re.compile(r"كبار\s+الم(ساهمين|لاك)")),
  "foreign":       (re.compile(r"/foreignownershipdetails/"),
                    re.compile(r"ملكية\s+الأجانب|الملكية\s+الأجنبي")),
}

def tab_links(html, base, company_id=None):
    found = {}
    for href, label in re.findall(r'<a[^>]+href="([^"]+)"[^>]*>(.*?)</a>',
                                   html, re.S | re.I):
        url, txt = href.replace("&amp;", "&"), _text(label)
        for key, (by_path, by_text) in TABS.items():
            if key in found:
                continue
            if not (by_path.search(url) or (txt and by_text.search(txt))):
                continue
            # شرطٌ حاسم: رابطٌ لا يحمل معرِّفَ الشركة رابطُ سوقٍ عامّ.
            if company_id and not re.search(
                    rf"(?:^|/|=){re.escape(company_id)}(?:/|$|&)", url):
                continue
            found[key] = url if url.startswith("http") else base + url
    return found
```

**ثلاثةُ دروسٍ مقيسة:**

- **الاسمُ المفترَضُ يخيب:** كتبتُ «الملكية الأجنبية» والصفحةُ تقول «ملكية
  الأجانب»، و«صفقات كبار المساهمين» وهي «الصفقات الخاصة»، و«تقديرات
  المحلّلين» وهي «توصيات المحللين». ثلاثةٌ من أربعة. فالمسارُ أثبتُ من
  النصّ، والنصُّ سندٌ ثانٍ.
- **رقمٌ صحيحٌ في مكانٍ خاطئٍ أسوأُ من الغياب:** في الصفحة روابطُ سوقٍ
  عامّةٌ بالأسماء نفسِها؛ فلو أُخذت عُرض جدولُ السوق تحت اسم شركة.
- **لا `<table>` في كثيرٍ من المواقع الحديثة:** قِيس صفرُ جداولَ في 509
  ألفَ حرف. فيلزم قارئُ حاويات يطابق الفتحَ بالإغلاق **بمكدَّس** ويأخذ
  **أصغرَ** كتلةٍ تجمع الاسمَ والقيمة (تعبيرٌ نمطيٌّ يرفض التداخل يلتقط
  الأعمقَ فقط فيعود صفراً).

## ٤ب· اقرأ كيف ينشر المصدرُ نفسُه — ثمّ اجلبها مثله

قال المالك: «انظر أوّلاً لأرقام كيف يجلبها واجلبها مثله». وهي القاعدةُ
التي كلّفني خرقُها دوراتٍ كاملةً (D296): كنتُ أطرق مساراً بصيغِ نداءٍ من
عندي — سبعَ صيغٍ مخترَعة — والمسارُ أصلاً لا يفتح على المعنى المطلوب.

**الشكلُ الذي ينشر به المصدرُ معنًى ما ليس واحداً:**

| الشكل | كيف يُقرأ |
|---|---|
| نقطةُ JSON خلف الصفحة | يُكتشَف اسمُها من الصفحة (البند ٢) |
| جدولٌ في صفحةٍ بشرية | قارئُ حاوياتٍ بمكدَّس (البند ٤) |
| **سجلٌّ من مقالاتٍ مؤرَّخة** | وسمُ موضوعٍ ← مقالاتُه ← جدولُ كلٍّ منها |

و«أرقام» تنشر **الصفقاتَ الخاصة** بالشكل الثالث: مقالةٌ لكلّ جلسة («تاسي:
٧ صفقات خاصة بقيمة ١٥٧٫٢ مليون ريال») فيها جدولُ الصفقات، ومجموعُها تحت
وسمِ موضوعٍ مرتَّبٍ بالأحدث. فالسجلُّ الأسبوعيُّ والشهريُّ موجودٌ فعلاً،
وكان سؤالي يذهب إلى بابٍ آخر. **واسمُ المسار يُقرأ حرفياً**:
`shareholders-history-deals` سجلٌّ لا لقطة، وهو صفقاتُ كبارِ الملّاك لا
الصفقاتُ الخاصة.

### والخطّةُ في جلسةٍ واحدة — لا نداءٌ منفصلٌ لكلّ مرحلة

موقعٌ ينشر على مرحلتين (صفحةٌ تُعطي الكوكيزَ ورمزَ الحماية، ثمّ نداءٌ
يحملهما) لا يُقرأ بنداءين مستقلّين: كلُّ نداءٍ جلسةٌ جديدةٌ تجمع الكوكيزَ
ثمّ ترميها. فالجلبُ يصير **خطّةً** تُنفَّذ في جلسةٍ واحدةٍ منتحِلة:

```python
async def smart_flow(plan, *, warm=None, timeout=45):
    """خطّةُ طلباتٍ في جلسةٍ واحدةٍ — `plan` مولِّدٌ متزامن:
    يُنتج مواصفةَ طلبٍ ويستقبل (الحالة، النصّ) فيقرّر التالي."""

def _plan(days):                       # مثالٌ مقيس
    _, home = yield {"url": ARGAAM_HOME}
    index = _index_from_nav(home) or TAG_INDEX          # القائمةُ تدلّ
    for page in _index_pages(index):
        _, body = yield {"url": page, "referer": ARGAAM_HOME}
        for href, _title in _index_links(body):         # مقالاتُ المعنى وحدَها
            _, art = yield {"url": href, "referer": page}
            at = _article_date(art)                     # تاريخُ إفصاحها
            if at and at < floor:
                return deals, log, n                    # الفهرسُ زمنيّ: توقّف
            deals += rows_from_html(art, at=at.isoformat())
```

**والفرقُ قِيس** على خادمٍ محليٍّ يضع كوكيزاً في الصفحة ويطلبها في نداء
البيانات: الخطّةُ في جلسةٍ واحدةٍ ردَّت `200 ROWS`، والنداءانِ المنفصلانِ
`403 NOCOOKIE`. فالعطبُ كان بنيوياً لا في المعاملات.

### ثلاثُ قواعدَ تمنع الاختلاق في هذا الشكل

- **وضعُ المقالة يقرأ جدولاً فقط.** المقالةُ نصٌّ فيه أرقامٌ كثيرةٌ ليست
  صفقات؛ وقارئُ الحاويات هو نفسُه الذي اختلق «الدخول/7759» (D293). فإن
  لم يكن في المقالة جدولٌ فالجوابُ لا شيء.
- **الاسمُ يُحلّ رمزاً بمطابقةٍ واحدةٍ فقط.** مقالاتُ «أرقام» تكتب الاسمَ
  القصيرَ («الراجحي») بلا رمزِ تاسي، وتربطه بمعرِّفها الداخليّ. فيُطابَق
  الاسمُ بصورةٍ موحَّدةٍ (بلا تشكيلٍ ولا همزاتٍ مختلفة)، وما طابق اسمين
  يُترك — المطابقةُ المتعدّدةُ اختلاقٌ مؤجَّل.
- **الكمّيةُ يُصدّقها حاصلُ الضرب.** ترتيبُ الأعمدة ليس عهداً: تُختار
  الكمّيةُ التي `الكمّية × السعر` موجودٌ في الصفّ نفسِه — تصديقٌ داخليٌّ
  لا ترتيبٌ مفترَض.

## ٥· ترتيبُ الطبقات — يُكتب مرّةً في البابِ الواحد

```
تداول (رسميٌّ مدقَّق) ← أرقام (تغطيةٌ واسعة) ← ياهو (آخرَ الوسائل)
```

يُكتب هذا الترتيبُ في **موضعٍ واحد** (بابُ البيانات)، لا في كلّ مسار.
والمطابقةُ **بندًا بندًا**: غيابُ بندٍ في الرسميّ لا يُلغي قراءةَ غيره من
الطبقة التالية. ويُعلَن مصدرُ كلّ رقمٍ في مخرَجه.

```python
async def get_financials(self, symbol):
    rows = _xbrl(symbol, "annual")                 # الطبقةُ الرسمية
    if rows:
        return {"periods": rows, "source": "تداول — XBRL"}
    return await self._provider().get_financials(symbol)   # آخرَ الطبقات
```

## ٦· انضباطُ الزمن: الحيُّ والإغلاقُ ليسا واحداً

سؤالان لا سؤال:

| السؤال | القاعدة |
|---|---|
| **أعرضُه لحظياً؟** | طزاجةٌ صارمة (‏≤ 300 ثانية). سعرٌ عمرُه ساعتان داخلَ الجلسة **كذبٌ** لا تأخّر. |
| **أستعمله في حسابٍ؟** | يُقبل آخرُ إغلاقٍ **حين يكون السوقُ مغلقاً فعلاً** (بحاكم الأطوار لا بالساعة)، بعمرٍ أقصاه أيّامٌ قليلة، **ويُقال إنه إغلاق**. |

وخلطُهما كلّفنا يومين في الأسبوع: اللقطةُ ترفض نفسَها في العطلة فيفقد
التطبيقُ السعرَ والعمقَ والتقييمَ — **والرقمُ عندنا**.

> **قاعدةٌ حاكمة:** الجهلُ ليس حكماً. لا مُدخَلَ ⇒ يُحذَف المفتاح. مُدخَلٌ
> مرفوضٌ ⇒ يُكتب `None` صريحاً. ولا يُصفَّر شيءٌ لم يُقرأ.

## ٧· مزالقُ قِيست — لا تُكتشَف إلا بالتجربة

## ٨· كيف تُنقَل إلى مشروعٍ آخر

١. `pip install curl_cffi` — وأضف مَعبرَ القسم ١ كملفٍّ واحد.
٢. افتح الصفحةَ المستهدَفة واطبع: الحالة · الطول · عددَ `<table>` ·
   أسماءَ النداءات (`=NJ…=/`) · أكثرَ أصناف الحاويات تكراراً.
   **اقرأ الشكلَ قبل أن تكتب قارئاً** — كلُّ قارئٍ بنيتُه على ترجيحٍ عاد
   صفراً وأنفق جولةَ قياسٍ كاملة.
٣. اكتشف النقطةَ من الصفحة (القسم ٢)، ولا تُثبّت مساراً.
٤. إن عادت «200 وصفرُ صفوف» فالمحتوى مرسومٌ بسكربت ⇒ طبقةُ المتصفّح
   المقيَّدة (القسم ٣).
٥. رتّب الطبقاتَ في بابٍ واحد (القسم ٥)، واحفظ كلَّ قراءةٍ **بتاريخها
   ومصدرها** وبعمرٍ أقصى.
٦. لكلّ عطبٍ تكتشفه: **سجّله واكتب له حارساً يمنع عودته**، وأثبت الحارسَ
   **أحمرَ** على الشيفرة القديمة قبل إصلاحها. حارسٌ لم يُرَ أحمرَ لا يُعلم
   أنه يحرس شيئاً.
